# Eagle AXS system overview

Complete installation and setup in the order described by the manual. Do not begin a new section until the previous sections are complete.

## Compatibility and service references

- AXS components are compatible only with other AXS components. Consult the Compatibility Map AXS Components for compatibility information.
- When this guide references a separate manual, find it at [sram.com/service](https://www.sram.com/service).
- SRAM components are designed only for pedal-powered or pedal-assisted bicycles.
- Specialized tools and supplies are required. SRAM recommends having a qualified bicycle mechanic install SRAM components.

## SRAM AXS app

Download the SRAM AXS app to create a SRAM account, add components, and customize the AXS system. The app can:

- Connect components through Bluetooth.
- Build and personalize multiple bike profiles.
- Monitor bike performance and readiness.
- Customize component behavior.
- Assign custom actions to controls.

All AXS components must be paired into one system before they can be customized in the app. Pairing multiple systems, such as an AXS seatpost and drivetrain, starts with one primary component.

Install the latest SRAM AXS app and component firmware for optimal performance and compatibility. Firmware updates are performed through the app.

> **Notice:** An e-bike motor must remain powered on while updating firmware on a rear derailleur connected by an extension cord. If the e-bike powers off during the update, the rear derailleur could be damaged.

## e-MTB and Pedelec multi-shift

Multi-shift is disabled by default on SRAM Eagle AXS systems. On an e-MTB or Pedelec, use an Eagle chain, Eagle cassette, and AXS rear derailleur with the SRAM AXS controller's multi-shift disabled to protect the components and preserve the warranty.

Multi-shift can be enabled from the system's Drivetrain Settings in the SRAM AXS app. The complete SRAM warranty is available at [sram.com](https://www.sram.com).

### AXS rear derailleur

- Upper pulley
- LED indicator

- Extension cord
- Battery protector
- SRAM battery
- High- and low-limit screws
- Cage Lock button

## Battery handling

Hands and gloves must be clean before handling a SRAM battery. Sunscreen and hydrocarbon cleaners can cause the battery to crack.

Remove the battery cover and charge the battery. Consult the SRAM Battery and Charger user manual for charging, maintenance, and travel instructions.

Do not discard the battery cover. Install it whenever the battery is not attached to the charger or derailleur so the terminals remain protected.
