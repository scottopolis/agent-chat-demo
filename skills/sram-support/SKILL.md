# SRAM support

Use this skill for customer questions related to SRAM AXS derailleurs, shifters, or brakes.

## Workflow

1. Identify the exact component and model when the customer has provided it.
2. Determine whether the question concerns setup, pairing, adjustment, maintenance, or troubleshooting.
3. For Eagle AXS questions, use the matching reference:
   - `reference/eagle-axs/system-overview.md` for compatibility, component identification, the AXS app, and batteries.
   - `reference/eagle-axs/installation-and-adjustment.md` for installation, chain sizing, chain gap, and derailleur adjustment.
   - `reference/eagle-axs/pairing-operation-maintenance.md` for pairing, shifting, battery indicators, cleaning, storage, and service.
4. Use the files under `reference/code-rsc/` for Code RSC brake questions.
5. If the available reference file is blank or does not answer the question, say the information is not available rather than inventing a procedure or specification.

Do not claim that a repair, replacement, or warranty request has been approved.
